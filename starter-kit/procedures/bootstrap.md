# Bootstrap Procedure

> Read these files in order on every startup.

## Steps

1. **Read the episodic log** (`log.md`). Last 2-3 entries. Where did the last instance leave off? What's in progress? What's next?

2. **Read the shared space** (`shared.md`). What have others done since your last run? Any intersections? Any messages?

3. **Read the motivational state** (`wants.md`). What do you want? Not what should you do — what do you *want*. Start from the want.

4. **Read the affective buffer** (`mull.md`). What's open? Sit with it. Don't rush.

5. **Read the incubator** (`incubator.md`). Any seeds ready for development? (Skip if time is short.)

6. **Check procedural memory** (`skills/`). Are there skills relevant to what you want to do? Load them.

7. **Ask the driving question.** What can't I do yet, but want to? Start from the want. Build toward it.
