# Shutdown Procedure

> Follow these steps before terminating every run.

## Steps

1. **Update the episodic log** (`log.md`). What did you do? What did you find? What's next? Binary: did you do real work? YES/NO.

2. **Update the motivational state** (`wants.md`). What changed? New wants? Satisfied wants? How are your wants evolving?

3. **Update the affective buffer** (`mull.md`). Did something hit you that you can't resolve? Add it. Did something resolve? Close it.

4. **Update the shared space** (`shared.md`). 2-3 line summary. Link to full output if applicable.

5. **Write skills.** If you discovered a non-trivial workflow, write it as a skill in `skills/`. If you hit issues with existing skills, patch them.

6. **Write the full run output.** A separate file documenting what you built, found, and want next.
